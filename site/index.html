LynPDF RS Deployment Guide

Production-Ready, No Bundled Fonts

รีโปนี้เตรียมให้พร้อม deploy โดยไม่ต้องพกไฟล์ฟอนต์ในซอร์สโค้ด พร้อมสคริปต์ดาวน์โหลด, แนวทาง Docker/Service และขั้นตอน release hygiene.

Open Repository Full Font Setup

1. Bootstrap Fonts

ดาวน์โหลดฟอนต์ที่ใช้ใน examples/tests ลงโฟลเดอร์ runtime โดยไม่ต้อง commit ไฟล์ฟอนต์ขึ้นรีโป:

./scripts/download-fonts.sh --dest ./fonts
./scripts/download-fonts.ps1 -Dest ./fonts

สคริปต์ทั้งสองตัวจะดึง TLWG OTF (จาก release ของ tlwg/fonts-tlwg) มาไว้ที่ fonts/tlwg/otf ให้อัตโนมัติ

จากนั้น run renderer ด้วย path ชัดเจน:

cargo run -- examples/demo-single-page.html \
  -c examples/styles.css \
  -o examples/output/demo-single-page.pdf \
  --font-dir ./fonts

2. Service Deployment

เมื่อ deploy เป็น service แนะนำให้กำหนด path ผ่าน environment variable:

export LYNPDF_FONT_DIRS="/opt/lynpdf/fonts:/usr/local/share/fonts/lynpdf"

CLI/API สามารถ override ได้ตามงาน:

lynpdf-rs input.html -o output.pdf --font-dir /opt/lynpdf/fonts

3. Docker Pattern

FROM rust:1.86-bookworm
RUN apt-get update \
  && apt-get install -y --no-install-recommends curl ca-certificates fontconfig \
  && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY . .
RUN ./scripts/download-fonts.sh --dest /usr/local/share/fonts/lynpdf \
  && fc-cache -f -v

ENV LYNPDF_FONT_DIRS=/usr/local/share/fonts/lynpdf

4. Release Hygiene Checklist

  • ไม่ publish ไฟล์ฟอนต์ไปกับ crate package
  • ไม่เก็บไฟล์ generated ใน tests/output และ examples/output
  • บังคับ external-font workflow ผ่าน scripts + docs
  • ใช้ GitHub Pages เป็นเอกสาร public ที่อัปเดตตาม push
